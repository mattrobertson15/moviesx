# RPI phase artifacts land here

Per [METHODOLOGY.md](../docs/METHODOLOGY.md), each RPI phase produces a written artifact:

- `YYYY-MM-DD-<release number>-<topic>-research.md`
- `YYYY-MM-DD-<release number>-<topic>-plan.md`
- `YYYY-MM-DD-<release number>-<topic>-changes.md`
- `YYYY-MM-DD-<release number>-<topic>-review.md`

These are the audit trail. Commit them with the code they describe.
